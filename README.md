# PhD-Journey

This is my application through the PhD Journey in Japan at Nagoya University.

## Web-API application

- **Controller**:
    - The research projects as submodules.
    - Base Controllers for web base management.
- **Images**:
    - Each folder will contain the figure for research project.
- **Entities**:
    - Contain the entities of Database converted to ```Class Entities```.
- ```config.py```: all the configurations for APIs and DB connection.
- ```app_factory.py```: setup the main factor for main run.
- ```run.py```: main file to start application.
- ```Dockerfile```: create development environment.
